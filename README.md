# portfolio2026

Портфолио-страница Daria Bodaikina — Senior / AI Product Designer.

**Живая версия:** https://dbodaikina-eng.github.io/portfolio2026/

## Структура

| Путь | Что |
|---|---|
| `index.html` | Сайт. Один статичный файл, без сборки и зависимостей: открывается локально двойным кликом и работает на GitHub Pages. |
| `assets/` | Картинки: showreel, кейс, фото правой панели, слои кита-курсора. |
| `handoff/REPRODUCE.md` | Полная спецификация дизайна — палитра, шрифты, сетка, структура, логика курсора. Можно отдать нейросети, чтобы воспроизвести макет с нуля. |
| `handoff/source/` | Исходник в формате Design Component + рантайм, если нужно продолжать работу в редакторе. |

Офлайн-монолит на 25 МБ (всё зашито в один файл) в репозиторий не кладём — он больше лимита веб-загрузки GitHub; `index.html` + `assets/` дают то же самое и грузятся быстрее.

## Как включить публичную ссылку

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
Через 1–2 минуты страница живёт по адресу выше.

## Как править

Правки — прямо в `index.html`: вся вёрстка инлайновая, классов и препроцессоров нет.
Тексты ищутся поиском по файлу, картинки заменяются в `assets/` с теми же именами.
